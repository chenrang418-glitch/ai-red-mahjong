# AI 红中麻将（光山离线 AI 版）

这是一个可直接在浏览器中游玩的四人红中麻将：你与三个本地 AI 对局，不接入大模型，不上传牌局，也不需要安装桌面软件。项目可在 Windows 本地运行，也可部署为静态网站公开访问。

## 直接游玩

已构建过项目时，双击 `启动游戏.cmd`，浏览器会打开：

```text
http://127.0.0.1:4173
```

服务只监听本机回环地址，局域网和互联网无法访问。关闭浏览器不会清除牌局；下次打开可继续。需要停止服务时，可在任务管理器结束对应的 `node.exe`，或者在手动运行服务的终端按 `Ctrl+C`。

公开网站与本地版本使用相同的纯前端引擎。每位访问者的积分、存档、声音设置和牌谱只保存在自己的浏览器中，不会上传或与其他设备同步。

首次从源码运行：

```powershell
# PowerShell，进入项目目录后执行
npm install
npm run build
npm start
```

开发模式：

```powershell
npm run dev
```

## 第一版完整功能

- 112 张牌：万、筒、条各 1～9 四张，加 4 张红中。
- 仅允许自摸；支持普通胡和未副露七对。
- 红中可作万能牌，但不能碰、明杠、暗杠或补杠。
- 不吃牌；碰和明杠采用“先喊先得”，不按座次，也不设杠高于碰。
- 四家各投两枚骰子，唯一最高者首庄；后续赢家坐庄，流局留庄。
- 每局固定预留最后 6 张码牌，正常摸牌和杠后补牌不会碰到码区。
- 有红中胡时抓 4 张码，无红中胡时抓 6 张；1、5、9、红中算码。
- 自摸向另外三家各收 1 分，每中一码再向三家各收 1 分。
- 暗杠、补杠向另外三家各收 1 分；明杠只向出牌者收 1 分。杠分即时结算并保留。
- 有限积分支持四家分别设置初始积分；有人积分归零立即结束整场，支付不会出现负数。
- 无限模式不设破产，只记录每人的本场净分。
- 三个 AI 可在开局前或对局中分别切换性格、智能程度和反应速度，下一次决策立即生效。
- 开局页直接提供玩法规则入口和 AI 性格、智能、速度的选择说明；对局中也可随时查规则或调整 AI。
- AI 只读取自己的手牌、公开副露和牌河，不读取其他玩家暗牌。
- 自己摸牌后会把新摸牌单独放在手牌右侧并标注“刚摸”，顶部提示也会显示具体牌名。
- 对局音乐以及摸牌、出牌、碰、杠、胜负等音效均由浏览器本地生成，可分别调节音量或一键静音，不访问网络。
- 当前牌局自动保存在浏览器本地；支持继续上次牌局、完整步骤回放、牌谱明牌模式、JSON 导出和删除。
- 规则、投骰、积分流水、胡杠码统计和整场排名均在界面中可查看。

## AI 设计

AI 不依赖联网模型。它基于可见牌计数、牌型结构、有效进张、红中保留价值、七对进度和一次摸牌前瞻做选择。

五种性格改变策略偏好：快攻型偏向副露，七对型偏向对子，无红中策略型降低红中依赖，平衡型对三种核心策略等权评估，真人波动型优先选择当前牌型更合适的策略但保留小概率判断失误。菜鸡、凡人、猿神三级智能控制评估深度；闪电、猴急、微醺、入梦四档速度只控制模拟思考与抢牌反应节奏，不让网络或机器速度决定输赢。

抢碰/抢杠拥有独立的真人化反应延迟。默认抢牌窗口为 4 秒，开局时可在 2～7 秒之间调整。

## 游戏流程

```text
开局设置 → 四家投骰定首庄 → 发牌并预留六码
→ 庄家先出牌 → 弃牌抢碰/抢杠窗口
→ 无人抢则下家摸牌 → 判断自摸/暗杠/补杠 → 出牌
→ 自摸后抓码并结算 → 赢家坐庄进入下一局
→ 流局留庄；有限模式有人归零则整场结束
```

## 验证

```powershell
npm run test:run
npm run build
```

自动测试覆盖胡牌、七对、红中限制、112 张守恒、六码隔离、三种杠分、自摸抓码、余额封顶、无限积分、庄家轮换和 AI 暗牌隔离。测试采用小而有针对性的场景，不批量模拟无意义的大量牌局。

## 项目结构

```text
src/game/                 纯 TypeScript 规则、胡牌、AI、持久化
src/composables/          对局调度、AI 轮转、抢牌计时
src/components/game/      开局、牌桌、AI 设置、牌谱回放
tests/                    规则和引擎测试
server.mjs                仅本机可访问的静态网页服务
启动游戏.cmd              Windows 双击启动入口
```
