# Task: 麻将经线逻辑推测算法知识库整理

## Objective
将麻将实战中的"经线逻辑"（对手出牌推测规则）系统化整理为 AI 可识别的自然语言规则

## Key Reasoning
- 经线逻辑是麻将中通过对手弃牌推断手牌的核心方法论
- 需要覆盖：连续舍牌（1→2断3）、同线牌（1-4-7线）、搭子拆解、牌河全局分析、听牌状态推测等维度
- 每条规则拆分为独立推测函数（IF→THEN模式），可直接映射为算法代码
- 增加了置信度机制、记忆衰减、优先级排序等工程化设计
