# 左慈【化身】技能兼容审计

更新时间：2026-09-04。

本审计针对项目当前的经典标准、风、火、林、山包。娱乐包不进入化身池；本局已经上场的武将、左慈自身和已被其他左慈持有的化身也不进入剩余池。

## 判定原则

- 可声明：已注册运行时的普通武将技能，包括主动技、触发技、锁定技、转换技和能够被其他技能授予的普通技能。
- 规则排除：主公技、限定技、觉醒技、【化身】、【新生】。
- 不允许用“实现复杂”作为排除理由。任何普通技能缺少运行时都会进入 `incompatibleBug`，并由 `sanguosha-zuoci.test.ts` 令测试失败。
- 资格来自 `SkillRuntime.lord / limited / awakening` 元数据，不维护容易过期的人工白名单。

## 当前规则排除项

- 主公技：护驾、激将、救援、黄天、血裔、颂威、暴虐、制霸。
- 限定技：涅槃、乱武。
- 觉醒技：凿险、志继、若愚、魂姿。
- 左慈自身：化身、新生。

## 当前审计结论

- 所有其余已登记经典技能均进入可声明集合。
- `incompatibleBug` 必须为 0；这项结论由测试从完整武将目录和实际技能注册表实时计算，不依赖本文档手工计数。
- 临时技能以 `huashen:<playerId>` 来源绑定，切换时原子替换，并清除尚未开始的旧技能排队项。
- 化身改变后的势力、性别统一通过 `effectiveKingdomOf` / `effectiveGenderOf` 查询；主公技阵营判定、结姻、离间、雌雄双股剑等规则消费方均走动态值。
- 断肠只关闭武将技能：当前化身不再公开生效，势力和性别恢复左慈本体；装备能力不受影响。

每次新增武将或技能后，必须同时补齐运行时元数据并运行资格审计测试。若出现普通技能进入 `incompatibleBug`，应修复技能接入，不得把它加入排除名单绕过失败。
