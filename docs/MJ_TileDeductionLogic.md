# 麻将经线逻辑 — 对手出牌推测知识库

> 目标：将麻将实战中的经验规则整理为 AI 可识别的自然语言规则，

---

## 一、牌型基础概念

### 1.1 花色与编号
```
万(W):  1W ~ 9W
筒(T):  1T ~ 9T
条(B):  1B ~ 9B
字牌:   红中(HZ)
```

### 1.2 玩家手牌状态
```
待牌(Waiting):     已有搭子，等某张牌组合
听牌(Tenpai):      差一张就胡
一面听(Tan-chan):  听1张
两面听(Ryanmen):   听2张
三面听(Sanmen):    听3张
坎张听(Kanchan):   听嵌张
边张听(Penchan):   听边张
单骑听(Tanki):     听单张对子
```

### 1.3 数字牌关系术语
```
同线牌(三条筋)：    1-4-7 / 2-5-8 / 3-6-9
  核心：同一线上的牌互相有替代关系
邻牌：             1-2, 2-3, ..., 8-9
隔牌(嵌张对)：     1-3, 2-4, ..., 7-9
间两张/三张：      1-4, 2-5, ..., 6-9
```

## 二、核心推测规则库

> 每一条规则=一个独立推测函数，可并行评估，最后汇总置信度评分

---

### 规则组 A：连续舍牌推测（"经线"核心）

#### A1. 先出1后出2（同花色）
```
IF 玩家在某花色中先弃1、再弃2（第1~4轮内）
THEN 推测：
  A1a. 玩家没有3（否则会留着等1-2-3顺子）
  A1b. 玩家没有4（否则有2-4嵌张，不会拆2）
  A1c. 玩家手牌中该花色没有1和2了（全打光了）
  A1d. 玩家短期内不需要该花色的一和二区低位牌
  A1e. 该牌对其他玩家相对安全（可放心打3、4）
置信度：75%
特殊：如果是在多轮后弃1再弃2（第5+轮），可能是一面听的换听行为
```

#### A2. 先出9后出8（同花色）
```
IF 玩家在某花色中先弃9、再弃8（第1~4轮内）
THEN 推测：
  A2a. 玩家没有7（否则会留着等7-8-9顺子）
  A2b. 玩家没有6（否则有6-8嵌张，不会拆8）
  A2c. 玩家手牌中该花色没有9和8了
  A2d. 玩家短期内不需要该花色的高位牌
置信度：75%
```

#### A3. 先出2后出1（同花色，反向出牌）
```
IF 玩家先弃2、后弃1
THEN 推测：
  A3a. 玩家有3和4或3与5的可能性低
    - 推理：如果有2-4嵌张，会先弃4而不是2
    - 推理：如果有2-3两面搭，不会先弃2
  A3b. 更可能是孤张依次清理（先拆中张再拆边）
  A3c. 如果弃2后过几轮才弃1，可能是1-2边张搭拆解
  A3d. 可能有5+待该花色成顺子后被丢弃
置信度：50%（比A1/A2弱）
```

#### A4. 先出8后出9（同花色，反向出牌）
```
IF 玩家先弃8、后弃9
THEN 推测：逻辑同A3，镜像对称
置信度：50%
```

#### A5. 先出4后出7（同线牌，1-4-7线）
```
IF 玩家先弃4、后弃7
THEN 推测：
  A5a. 玩家不需要该线上的牌（1-4-7线被放弃）
  A5b. 玩家手牌中该花色≤3张且都是低位
  A5c. 1和4和7该花色大概率不在手
  A5d. 其他玩家打1、4、7相对安全
置信度：60%
```

#### A6. 先出6后出3（同线牌，3-6-9线）
```
IF 玩家先弃6、后弃3
THEN 推测：逻辑同A5，3-6-9线被放弃
置信度：60%
```

#### A7. 先出5后出8（同线牌，2-5-8线）
```
IF 玩家先弃5、后弃8
THEN 推测：
  A7a. 2-5-8线可能被放弃（但需注意5的特殊性）
  A7b. 5是中心牌，弃5说明该花色基本不在手中
  A7c. 玩家在该花色上≤1-2张孤张
置信度：55%
⚠️ 5是特殊牌（可组成最多顺子），弃5的信号强度大于其他中张
```

### 规则组 B：边张/中张出牌推测

#### B1. 先出1（第1~2轮）
```
IF 玩家在第1~2轮内先出1（任意花色）
THEN 推测：
  B1a. 该花色没有2-3（否则会是1-2-3顺子）
  B1b. 该花色可能有1对子（留1张）
  B1c. 极低概率有1-2边搭
  B1d. 该花色的其他牌大概率是孤张
置信度：70%
```

#### B2. 先出9（第1~2轮）
```
IF 玩家在第1~2轮内先出9
THEN 推测：同B1镜像
置信度：70%
```

#### B3. 不出1也不出9（第3+轮才出）
```
IF 玩家到第3+轮才出1或9
THEN 推测：
  B3a. 可能有1-2或8-9边张搭，后来拆了
  B3b. 可能有1对子或9对子，留了一段时间
  B3c. 可能在凑清一色/混一色，先处理其他花色
置信度：40%
```

#### B4. 第1~2轮出中张(4/5/6)
```
IF 玩家在第1~2轮出4或5或6
THEN 推测：
  B4a. 该花色完全没有成搭可能（孤张处理）
  B4b. 5的特殊性：弃5=该花色最多1-2张孤张
  B4c. 玩家可能主攻其他花色，或已具听牌雏形
  B4d. 弃5比弃4/6的信号更强烈
置信度：80%（弃5）/ 65%（弃4/6）
```

### 规则组 C：搭子拆解推测

#### C1. 拆边张搭（1-2或8-9）
```
IF 玩家先出1（或9），几轮后又出2（或8）
THEN 推测：
  C1a. 拆了边张搭（1-2 或 8-9）
  C1b. 摸到了更好的搭子，或该搭子已无用
  C1c. 听牌概率提升（拆搭=手牌更集中）
  C1d. 3（或7）安全指数上升（不会再用这个搭子）
置信度：70%
```

#### C2. 拆坎张搭（2-4、3-5、4-6、5-7、6-8）
```
IF 玩家先出2后出4 或 先出4后出2
THEN 推测：
  C2a. 拆了2-4坎张搭
  C2b. 摸到了3的可能性低（否则就是1-2-3或2-3-4）
  C2c. 3相对安全（不会等3了）
置信度：65%

同理：
  3-5拆 → 4安全（置信度65%）
  4-6拆 → 5安全（置信度65%）
  5-7拆 → 6安全（置信度65%）
  6-8拆 → 7安全（置信度65%）
```

#### C3. 拆两面搭（3-4、4-5、5-6、6-7）
```
IF 玩家拆两面搭（如出牌3，数轮后出4）
THEN 推测：
  C3a. 出现了更好的听牌选择（很危险！）
  C3b. 可能已听牌或换成了三面听
  C3c. 2和5可能变成危险牌（3-4搭可听2-5）
  C3d. 其他玩家发牌不安全
  C3e. 拆两面搭是强信号：手牌在最后阶段
置信度：80%（拆两面搭是强信号，基本=换听/听牌）
```

### 规则组 D：单张与特殊牌推测

#### D1. 中张全部出完后的单张
```
IF 玩家3~4轮内打光了所有中张(3-7)
THEN 推测：
  D1a. 手牌中该花色只剩1或9或字牌
  D1b. 该花色在整个牌局中不会再出搭子
  D1c. 该花色的牌对所有玩家相对安全
置信度：70%
```

#### D2. 红中出牌推测
```
IF 玩家出红中
THEN 推测：
  D2a. 手牌已成型，不需要赖子替代
  D2b. 听牌概率极高（通常=手牌完成，红中用不上）
  D2c. 或者手上只有1个红中且手牌完整无缺口
  D2d. 注意：出红中≠必定听牌，新手可能胡乱出
置信度：60%（老手） / 30%（新手）
```

#### D3. 出牌时间反常
```
IF 玩家摸了某花色中张后、过1~2轮又打出
THEN 推测：
  D3a. 摸到了无用牌（该花色不成搭）
  D3b. 也可能在听牌前最后调整手牌
  D3c. 如果打的刚好是刚摸到的 = 摸到的牌没用
  D3d. 算法记录：摸X → 打X（摸切）= 对该花色没帮助
置信度：50%
```

### 规则组 E：牌河全局分析

#### E1. 缺一门判定
```
IF 玩家在6轮内未出某花色的任何一张
THEN 推测：
  E1a. 该花色可能全在手上（在做清一色/混一色）
  E1b. 玩家可能是"缺一门"打法
  E1c. 该花色中张对玩家极度危险
  E1d. 如果加上其他2个花色都有出牌→极高概率在凑清一色
置信度：
  6轮不出 = 40%
  8轮不出 = 60%
  10轮不出 = 80%
```

#### E2. 清一色预警
```
IF 条件同时满足：
  - 玩家只出2个花色的牌
  - 被隐藏花色从未出现过
  - 玩家多次吃/碰该隐藏花色
THEN 推测：
  E2a. 清一色概率 > 70%
  E2b. 绝对不要打该花色的中张牌
  E2c. 出边张(1/9)也极度危险
  E2d. 唯一安全选择：拆其他花色的搭子避铳
```

#### E3. 偏张打法检测
```
IF 玩家多次出同一花色的相邻牌（如1-2、2-3、8-9等模式）
THEN 推测：
  E3a. 该花色不成体系，玩家在清理孤张
  E3b. 玩家可能只是该花色手中牌少且散
  E3c. 不是做清一色信号
置信度：60%
```

#### E4. 全中张控牌
```
IF 玩家一直没有出某花色中张(3-7)但出了该花色的1和9
THEN 推测：
  E4a. 中张全部被保留，可能在做顺子搭
  E4b. 该花色是主要进攻方向
  E4c. 警惕：不要打该花色的中张
置信度：55%
```

### 规则组 F：听牌状态推测

#### F1. 换听检测
```
IF 玩家在平稳出牌多轮后，突然打出一张绝对安全牌（已出过的）
THEN 推测：
  F1a. 听牌概率+30%
  F1b. 玩家可能在换听（换更好的听牌）
  F1c. 之后所有牌打出一张少一张，都是危险牌
置信度：55%
```

#### F2. 单骑换搭检测
```
IF 玩家出1张，然后立刻摸打（不改变手牌数）
  且这张牌是上轮刚摸到的
THEN 推测：
  F2a. 可能是单骑换听（对子已换）
  F2b. 摸到的牌和打出的牌相同=摸切=对子没变
  F2c. 如果摸A打B（不同牌），可能是换听
置信度：40%
```

#### F3. 立直级信号（非立直麻将中参考）
```
IF 玩家连续打出多张已出过的安全牌
THEN 推测：
  F3a. 必然听牌（只能出安全牌）
  F3b. 所有未出过的牌都可能是危险牌
置信度：85%
```

#### F4. 出牌速率变化
```
IF 玩家出牌速度突然变慢（思考时间变长）
THEN 推测：
  F4a. 可能在判断危险牌（自己快听牌了）
  F4b. 有被别人胡的预感
  F4c. 听牌概率+25%
置信度：35%（在AI中实现需要模拟思考延迟）
```

### 规则组 G：碰/杠行为推测

#### G1. 不碰分析
```
IF 玩家有机会碰某牌但选择不碰
THEN 推测：
  G1a. 手牌很好，碰了会破坏手型（清一色/七对子等）
  G1b. 手上已有3-4个面子成型，不想暴露手牌
  G1c. 如果在后盘（听牌附近），可能是好手
置信度：50%
```

#### G2. 明杠分析
```
IF 玩家选择明杠
THEN 推测：
  G2a. 手牌已成型，杠+1面子=往前推进一步
  G2b. 明杠后多摸一张牌=可能直接听牌或胡
  G2c. 如果杠后打出的牌是安全牌→听牌概率+50%
  G2d. 杠后防守越严密→听牌可能性越高
置信度：40~60%（结合其他条件）
```

## 三、置信度汇总机制

### 3.1 多规则置信度加权公式
```
一条推测证据的最终置信度 = MIN(100%, 各规则置信度之和 × 衰减因子)

衰减因子 = 1 / (1 + 0.1 × 规则数量)
  - 第一条证据: 100%权重
  - 第二条: 90%权重
  - 第三条: 80%权重
  ...
```

### 3.2 输出格式（供算法参考）
```
❌ 玩家持有 X万的概率: <5% （强烈排除）
⚠️ 玩家持有 Y万的概率: 20-30%（概率低）
🔶 玩家持有 Z万的概率: 40-60%（可能持有）
🔴 玩家持有 W万的概率: >70%（大概率持有）
```

### 3.3 推测置信度分级
```
Level 0 (0-15%):    无信息
Level 1 (15-30%):   微弱信号
Level 2 (30-50%):   有一定参考价值
Level 3 (50-70%):   可信推测
Level 4 (70-85%):   高可信推测
Level 5 (85-100%):  几乎确定
```

## 四、算法架构建议

### 4.1 数据结构
```csharp
// 对手模型
class OpponentModel {
    // 各花色残余推测
    Dictionary<Suit, TileProbabilities> SuitProb;
    // 每张牌的安全评分（分越高越安全）
    Dictionary<Tile, double> SafetyScore;
    // 是否听牌
    double TenpaiProbability;
    // 可能的听牌方向
    List<Tile> PossibleWaitTiles;
}

class TileProbabilities {
    double Have1, Have2, ..., Have9;  // 持有概率
    int CardsHeld;                    // 推测持有张数
    bool SuitAbandoned;               // 花色是否放弃
}
```

### 4.2 推测流水线
```
[1] 初始化对手模型（均一概率）
    ↓
[2] 每轮对手出牌后，触发推测
    ↓
[3] 执行所有匹配的推测规则
    ↓
[4] 汇总置信度，更新对手模型
    ↓
[5] 根据对手模型计算安全牌排名
    ↓
[6] 输出：推荐出牌+理由
```

### 4.3 记忆衰减
```
旧信息的置信度随时间衰减：
- 1轮前：100%
- 2-3轮前：80%
- 4-6轮前：60%
- 7+轮前：40%（基本不参考）
```

## 六、适用性说明

### 适用于
- 广东红中麻将（杰哥打的类型）
- 日本麻将（立直规则增强版）
- 四川麻将（血战/血流，部分规则需调整）
- 台湾麻将（部分规则调整）

### 不适用于
- 极速麻将（出牌太快，无足够信息）需要调大时间窗口
- 二人麻将（需要适配）

### 注意事项
1. **运气永远>推测**：麻将40%运气+40%推测+20%技巧
2. **玩家风格差异**：谨慎玩家 vs 激进玩家的推测参数应不同
3. **错误累积**：一次错误推测会影响后续全局分析
4. **红中特殊性**：红中是赖子，对手的决策模式完全不同
5. **开局手牌质量**：起手好牌 vs 差牌的策略完全不同
