# 三国杀 ruleset-v1

## 版本边界

第一版采用经典 5～8 人身份局、标准包 108 张与军争篇 52 张，共 160 张。不额外加入界限突破的木牛流马，因此不是常见的 161 张扩展牌堆。

数据来源：

- [标准包卡牌（108）](https://wiki.biligame.com/sgs/标准包卡牌)
- [军争篇卡牌（52）](https://wiki.biligame.com/sgs/军争篇卡牌)
- [三国杀 OL 身份模式介绍](https://www.sanguosha.com/mode?id=0)
- [三国杀官方规则集 3.0：锦囊牌](https://gltjk.com/sanguosha/rules/card/scroll.html)
- [三国杀官方规则集 3.0：游戏流程](https://gltjk.com/sanguosha/rules/flow/game.html)

## 牌堆摘要

- 基本牌 85：普通/火/雷杀、闪、桃、酒。
- 锦囊牌 50：包含决斗、过河拆桥、顺手牵羊、无中生有、桃园结义、南蛮入侵、万箭齐发、五谷丰登、借刀杀人、无懈可击、乐不思蜀、闪电、火攻、铁索连环、兵粮寸断。
- 装备牌 25：武器、防具、+1 马、-1 马。
- 四种花色各 40 张，红黑各 80 张。
- 火杀 5、雷杀 9、酒 5、火攻 3、铁索连环 6、兵粮寸断 2。

## 当前已实现规则底座

- 确定性 seed、身份与洗牌。
- 独立牌区域与装备槽。
- 身份胜负边界。
- 统一距离、攻击范围与坐骑修正入口。
- 事件名称与处理器注册。
- 12 类 Request 数据结构与校验。
- 玩家私有视图与隐藏信息裁剪。
- 回放记录结构。
- 可中断六阶段状态推进和阶段跳过；摸牌阶段实际摸两张，弃牌阶段按当前体力生成定量 Request。
- 伤害修改/取消、濒死、按座次救援、桃/自救酒、死亡与身份公开。
- 击杀反贼摸三张、主公误杀忠臣弃牌，以及死亡后的统一身份胜负判定。
- 【杀】的距离/次数限制、【闪】响应、普通/火/雷伤害类型。
- 【桃】出牌阶段回复、【酒】每阶段一次与下一张杀伤害加一。
- 装备牌进入对应槽位及替换；武器范围进入统一距离入口。
- 【无中生有】摸两张及【无懈可击】多轮抵消链，包括“锦囊→无懈→再无懈”。
- 火焰/雷电铁索传播、传播中濒死暂停与恢复。
- 【乐不思蜀】非红桃跳过出牌、【兵粮寸断】非梅花跳过摸牌。
- 【闪电】黑桃 2～9 造成无来源 3 点雷电伤害，否则传递给下一名可放置角色。
- 延时锦囊在判定阶段翻牌前开启无懈链；乐/兵粮被抵消后弃置，闪电被抵消后继续传递。
