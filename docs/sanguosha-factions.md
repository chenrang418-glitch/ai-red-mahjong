# 纸上三国六势力接入规则

项目沿用既有字段名 `kingdom`，它是武将的正式基础属性，不是纯展示字段。唯一类型、固定顺序、名称和颜色均定义在 `src/sanguosha/shared/factions.ts`。

## 固定势力

| `kingdom` | 名称 | 主色 | 深色页面标题色 |
| --- | --- | --- | --- |
| `wei` | 魏 | `#315A8C` | `#78A9DF` |
| `shu` | 蜀 | `#3F7D4A` | `#7FBE87` |
| `wu` | 吴 | `#A94442` | `#DA7770` |
| `qun` | 群 | `#666A70` | `#AFB2B7` |
| `jin` | 晋 | `#75558A` | `#B692CA` |
| `shen` | 神 | `#C9972F` | `#E2BA58` |

固定展示顺序为魏、蜀、吴、群、晋、神。即使某势力暂时没有武将，规则页和艺术集仍保留分类标题。

## 新增武将

每个 `CharacterDefinition` 必须显式填写且只能填写一个合法 `kingdom`：

```ts
{
  id: 'simazhao',
  name: '司马昭',
  kingdom: 'jin',
  // 其余字段……
}
```

不要根据姓名、前缀或历史人物归属推断势力；“界、谋、SP、标”等版本概念也不能写入 `kingdom`。神版本武将应显式写 `kingdom: 'shen'`。

新增武将后，对局角标、选将卡角标、规则分组、艺术集分组、词条和势力技能判断会直接读取该字段，无需再修改页面映射。艺术集和规则页只给分类标题应用势力文字色，不向立绘或武将条目叠加角标。

## 联机与兼容

服务端状态仍以 `characterId` 为事实源，公开视图只同步已有的单个 `kingdom` 值，不同步名称或颜色，因此不会增加图片请求，也不会重复传输展示配置。旧房间由 `characterId` 回查当前武将表，缺少/尚未选定武将时客户端不显示角标，不会导致页面崩溃。
