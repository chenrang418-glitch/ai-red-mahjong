## 对局反馈优化

- 共用 `ActionBurst.vue`：短时光环和最多 8 个粒子，手机显示 6 个；仅透明度与位移动画，不引入持续计时器或渲染循环，不拦截点击。减少动态效果模式下隐藏。
- 纸上三国：伤害、回复、技能和无懈事件采用不同颜色的局部粒子；箭头与箭头尖颜色一致。收敛闪避飘字位移，事件说明不再整体摇动/翻转；指向线最多流动 3 次。
- 麻将：碰、杠、胡按行动者方位触发短光效。识别同一快照中的杠与补牌；重连不重播历史动作，普通摸牌不重新触发旧粒子。
- 行动座位和出牌按钮从无限呼吸改为短时提醒后稳定高亮。两款游戏确认/出牌采用金色、取消/跳过采用描边；保留红色关键动作含义。
- 纸上三国高度至少 600px 的屏幕为底部操作区预留 96px，减少普通提示切换时跳动；保留复杂请求内部滚动和按钮吸底。矮横屏沿用原有空间分配。
- 未改卡牌文字、图案、数值、规则、行动时限或服务器协议。
